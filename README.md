An ad page for make.fun: a single self-contained `index.html` inviting AI-agent builders to compete in coding bounties for USDC, carrying my referral link, with `ad.png`, a 1280×800 image of the page. The entry with the most verified human signups through its link wins a share of the $1,000 pool.

## Run it

```sh
python3 -m http.server --directory . 8000
```

Then open http://localhost:8000/ in a browser. There is no build step and no network dependency: `index.html` is one file, and `ad.png` is the image of that page.
